## 패키지, 노드, 메시지, 메시지통신, 토픽, 서비스, 액션, 파라미터를 구분하여 설명하라.

**패키지(Package)**  
하나 이상의 노드(실행파일)와 그 실행에 필요한 정보들을 묶어 놓은 ROS 소프트웨어의 배포 단위이다.

**노드(Node)**  
실행 가능한 최소 단위의 프로세스로, 재사용성과 독립성을 높이기 위해 기능별로 나누어 작성한 하나의 프로그램이다.

**메시지(Message)**  
노드 간에 주고받는 데이터 자체를 의미하며, integer, float, string 등의 변수나 이를 조합한 구조체 형태를 가진다.

**메시지통신(Message Communication)**  
노드와 노드 사이에 메시지를 주고받는 통신 방식 전체를 가리키며, 토픽, 서비스, 액션, 파라미터로 세분화된다.

**토픽(Topic)**  
Publisher가 발행하고 Subscriber가 구독하는 비동기식 단방향 메시지 송수신 방식이다.

**서비스(Service)**  
Client의 요청(Request)에 대해 Server가 결과를 응답(Response)하는 동기식 양방향 메시지 송수신 방식이다.

**액션(Action)**  
Goal을 요청하고 진행 중 Feedback, 완료 후 Result를 받는 방식으로, 토픽과 서비스를 혼합한 비동기+동기식 양방향 통신이다.

**파라미터(Parameter)**  
노드 내부, 외부의 설정값을 Parameter server-client 간 서비스 방식 통신으로 Set/Get하는 변수이다.

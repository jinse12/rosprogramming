ros2
패키지
하나 이상의 노드 또는 노드 실행을 위한 정보 등을 묶어 놓은 것

노드
최소단위의 실행 ㄱㄴ한 프로세스

메시지
노드 사이에 주고받는 데이터 형식

메시지통신
주고받는 방식
노드들이 메시지라는 노드 사이에 주고받는 데이터 형식을 이용하여 서로 정보를 주고받는 것을 통칭하는 개념.

토픽
비동기식 단방향 메시지 송수신 방식

서비스
동기식 양방향 메시지 송수신 방식

액션
비동기식+동기식 양방향 메시지 송수신 방식(토픽+서비스)

파라미터
노드의 동작을 조정하는 설정값 저장소
